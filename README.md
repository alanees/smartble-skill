# مهارة «الجدول الذكي» لـ Claude (smartble-skill)

مهارة (Skill) لـ Claude تجعله يشغّل موقع **الجدول الذكي — Smartble Pro** ([smartble.net](https://www.smartble.net)) نيابةً عن مدير المدرسة أو منسّق الجداول. يعمل Claude داخل المتصفح عبر إضافة **Claude in Chrome**، فيقرأ الصفحات وينفّذ الخطوات ويتحقق من النتيجة، ويطلب موافقتك قبل أي تعديل.

## ماذا تغطي المهارة؟

**الجدول الدراسي**
- إدخال الإسنادات (العلاقات التدريسية) من ملف PDF، ومقارنتها بنسخة معدّلة وتطبيق الفروق فقط.
- إضافة المعلمات وحذفهن، وأسماء الاختصار، وإغلاق حصص (مثل ساعة الرضاعة)، ورفع الحد الأقصى للحصص.
- نسخ الجداول وإنشاؤها واعتمادها، والتوليد الآلي ومراجعة جودة الجدول.
- تشخيص الجدول الناقص: حصص تسقط بصمت، وتكرار المادة في اليوم، وأيام ثقيلة وأخرى خفيفة. ومعالجة ذلك بعدد الحصص في الأيام، وبطاقات التوقيت المخصص، وأولويات القيود.
- نقل الحصص وتبديلها لموازنة أيام المعلمة.

**جدول الانتظار**
- بناء جدول حصص الانتظار بالمعالج، وتدقيق الخانات الناقصة، والتعديل اليدوي.

**المناوبة والإشراف** (جديد)
- استعادة جدول مناوبة «اختفى» من الموقع، بمقارنته يومًا بيوم بملف الإكسل المصدَّر.
- إضافة نوع مناوبة (مثل المناوبة الصباحية) وتعبئته من ملف، **دون إعادة التوليد**.
- تعديل الأيام التي بعد اليوم الـ١٣٠، وهي أيام لا يعرضها المعالج.
- نسخ جداول المناوبة واعتمادها، وتفسير عدم توازن التوزيع بين المعلمين.

## التثبيت

### في Claude Code
```bash
git clone https://github.com/alanees/smartble-skill ~/.claude/skills/smartble-skill
```
بعد ذلك يستدعي Claude المهارة تلقائيًا عندما تذكر «الجدول الذكي» أو «جدول الانتظار» أو «المناوبة»، أو تطلب تعديلًا في جدول المدرسة.

### في تطبيق Claude (claude.ai)
نزّل المستودع بصيغة ZIP (زر **Code ← Download ZIP**)، ثم ارفعه من **الإعدادات ← القدرات ← المهارات (Skills)**.

## المتطلبات
- إضافة **Claude in Chrome** متصلة بمتصفحك.
- حساب في الجدول الذكي، تسجّل الدخول إليه بنفسك. المهارة لا تكتب كلمات المرور أبدًا.

## مبادئ العمل
- **يتأكد من الحساب والجدول أولًا** قبل أي تعديل، لأن المتصفح قد يكون مسجّلًا في أكثر من مدرسة.
- **يشخّص بالقراءة فقط**، ثم يعرض التعديلات المقترحة في جدول، ولا ينفّذها إلا بعد موافقتك.
- **يأخذ نسخة احتياطية** قبل العمليات الكبيرة، ويتحقق من النتيجة بعد كل خطوة.
- **يجرّب على حساب تجريبي أولًا** حين يكون سلوك الموقع غير مؤكد والتعديل صعب التراجع.

## تنبيه
المهارة مبنية على واجهة الموقع كما هي في أكتوبر ٢٠٢٦، وقد تتغير الواجهة لاحقًا. راجع النتائج دائمًا قبل اعتماد أي جدول للمعلمين.
